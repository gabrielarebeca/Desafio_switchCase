# 💻 Desafio Switch-Case

Este repositório contém a solução para um **desafio de programação utilizando a estrutura de controle switch-case**. O objetivo é demonstrar o uso correto e eficaz dessa estrutura para resolver problemas específicos.

## 📌 Sobre o Projeto

O projeto foi desenvolvido para resolver problemas lógicos utilizando a estrutura de controle **switch-case**. Essa estrutura é comumente usada para testar um valor contra diferentes casos, tornando o código mais organizado e legível.

## ⚙️ Funcionalidades

- 🧩 Uso de **switch-case** para controle de fluxo em diversas situações  
- 🔄 Execução de diferentes ações dependendo do valor de entrada  
- 💡 Demonstração de boas práticas no uso de estruturas de controle

## 🛠 Tecnologias Utilizadas

- **C#** (ou outra linguagem, dependendo da implementação)
